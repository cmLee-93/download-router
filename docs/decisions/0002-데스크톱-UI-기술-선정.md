# ADR 0002: JavaFX를 데스크톱 UI에 사용

## 상태

채택

## 배경

Download Router는 대부분 백그라운드에서 동작하지만, 다음 기능을 제공하기 위한 설정 화면이 필요하다.

- 감시 폴더 설정
- 파일 이동 규칙 추가 및 수정
- 이동 내역 확인
- 프로그램 실행 상태 표시

Java 데스크톱 UI 기술로 JavaFX, Swing, SWT를 검토했다.

## 결정

Download Router의 설정 화면에는 JavaFX를 사용한다.

시스템 트레이 기능은 JavaFX에서 직접 제공하지 않으므로 AWT의 `SystemTray`를 함께 사용한다.

## 이유

- 규칙 목록과 설정 화면을 구성하는 데 필요한 UI 컴포넌트를 제공한다.
- 레이아웃과 스타일을 Swing보다 유연하게 구성할 수 있다.
- CSS를 이용해 화면 스타일을 분리할 수 있다.
- 화면이 확장되더라도 설정 UI를 구조적으로 관리하기 좋다.
- Gradle을 통해 JavaFX 의존성과 실행 환경을 명시적으로 관리할 수 있다.

## 고려한 대안

### Swing

JDK에 기본 포함되어 있고 AWT 시스템 트레이와 함께 사용하기 쉽다.

현재 기능만 구현하기에는 충분하지만, 규칙 편집 화면과 이동 내역 화면을 확장할 때 JavaFX가 화면 구성과 스타일 관리에 더 적합하다고 판단했다.

### SWT

운영체제의 네이티브 UI와 밀접하게 동작하지만, 플랫폼별 라이브러리와 배포 구성이 추가로 필요해 제외했다.

## 영향

- JavaFX 의존성과 Gradle 설정이 추가된다.
- 설정 화면은 JavaFX Application Thread에서 처리한다.
- 시스템 트레이를 위해 AWT 이벤트 스레드도 함께 다뤄야 한다.
- 배포 패키지에 필요한 JavaFX 모듈을 포함해야 한다.
