# ADR 0001: Java 21 사용

## 상태
채택

## 배경
Download Router는 다운로드 폴더를 감시하고, 사용자 규칙에 따라 파일을 이동하는 Windows 데스크톱 애플리케이션이다.

파일 이동 자체는 Python으로도 빠르게 구현할 수 있지만, 이번 프로젝트는 단순 스크립트보다 설정 화면과 시스템 트레이를 포함한 설치형 프로그램으로 만드는 것을 목표로 한다.

## 결정

Java 21을 사용한다.

## 이유

- 규칙, 파일 정보, 이동 결과를 명확한 타입과 클래스로 구성하기 좋다.
- JavaFX를 이용해 설정 화면을 만들 수 있다.
- JUnit을 이용해 파일 분류와 이동 규칙을 테스트하기 좋다.
- `jpackage`를 이용해 Java 실행 환경을 포함한 Windows 애플리케이션으로 배포할 수 있다.
- Java 21은 현재 사용하기에 충분히 안정적인 버전이며, 새 프로젝트의 기준 버전으로 적절하다고 판단했다.

## 고려한 대안

### Python

파일 감시와 이동 기능을 더 빠르고 간단하게 구현할 수 있다.

하지만 최종 목표가 Windows 트레이와 설정 화면을 포함한 데스크톱 애플리케이션이므로, 프로그램 구조와 배포 방식을 고려해 Java를 선택했다.

## 영향

- 초기 구현 속도는 Python보다 느릴 수 있다.
- JavaFX와 Gradle 설정이 필요하다.
- 프로젝트의 컴파일 기준은 Java 21로 고정한다.
